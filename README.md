# 🗔 Посмотри в окно

## 🚀 О проекте
Проект "Посмотри в окно" представляет собой минималистичный интерфейс для поиска и просмотра видеороликов. Пользователи могут вводить запрос в форму поиска, фильтровать результаты по различным параметрам и просматривать информацию о видео, включая его название, описание и превью.

## ✨ Функциональность
- **Поиск видео**: Пользователи могут вводить запрос в поле поиска и получать результаты с видеороликами.
- **Фильтрация по категориям**: Возможность фильтровать видео.

## 📦 Структура проекта
Проект состоит из следующих папок и файлов:

🔹 fonts/ — шрифты для сайта.
🔹 scripts/ — JS-скрипты.
🔹 styles/ — стили проекта.
    🔹 error.css — cтили для ошибок.  
    🔹 preloader.css —  cтили для прелоадера.
    🔹 style.css — основные стили сайта.
🔹index.html — основной HTML-файл проекта.


## 📥 Установка и запуск

1. Клонируйте репозиторий на свой компьютер:

```bash
git clone https://github.com/Loriveki/posmotri_v_okno.git
```
2. Откройте проект в вашем редакторе кода.  
3. Для работы проекта не требуется установка дополнительных зависимостей, все необходимые файлы уже включены в репозиторий.  
4. Для запуска откройте файл index.htm в браузере.
